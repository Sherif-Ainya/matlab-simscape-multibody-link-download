## 🛠️ خطوات التثبيت العامة داخل MATLAB (How to Install)

1. قم بتحميل ملف الـ **ZIP** الخاص بنظامك وملف **`install_addon.m`** المرافق له من صفحة الإصدارات المتوافقة مع نسختك.
2. افتح برنامج MATLAB كمسؤول (**Run as Administrator**).
3. في نافذة الأوامر (Command Window)، اكتب الأمر التالي (مع تغيير اسم الملف حسب إصدارك ونظامك) واضغط **Enter**:
   ```matlab
   install_addon('smlink.r2022a.win64.zip')
   ```

## 🔗 خطوات تفعيل الرابط داخل برنامج SolidWorks

بعد التثبيت بنجاح في ماتلاب، قم بإغلاق برنامج سوليدوركس تماماً، ثم اكتب الأوامر التالية في نافذة MATLAB لربط البرنامجين:

```matlab
regmatlabserver
smlink_linksw
```

عند فتح برنامج **SolidWorks**، اذهب إلى القائمة العلوية **Tools** -> **Add-Ins** وقم بتفعيل **Simscape Multibody Link** ليظهر لك خيار التصدير المباشر للمجسمات الميكانيكية بصيغة XML.
